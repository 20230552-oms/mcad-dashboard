# 해양 사이버사고 대시보드

MCAD · ADMIRAL 공개 데이터(2026-09-03 수집, 897행)를 기반으로 자산유형별 위협을 보여주고 IMO/IACS 통제 후보를 연결하는 정적 웹사이트입니다. GitHub Pages에 그대로 올리면 동작합니다(빌드 도구 불필요).

## 페이지 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 대시보드: 다중 필터, 자산유형×공격유형 히트맵, 목록, 상세(검증 단계 배지·통제 후보·근거 링크), CSV 내보내기 |
| `guide.html` | 업종별 대응: 조직 유형 선택 → 자주 기록된 위협 → 통제 후보 체크리스트(인쇄/PDF 가능) |
| `stats.html` | 통계: 연·월별 추이, 국가별·공격유형별·자산유형별 표+차트, 전체/아시아 범위 전환 |
| `controls.html` | 통제 매핑: 통제 항목별 연결 기록 수(역방향 조회), 규칙 ID 표 |
| `report.html` | 익명 제보 게시판: 자동 1차 점검, AI 사실확인 연동 지점, 나무위키식 상태 안내 |
| `glossary.html` | 용어 사전: 공격유형 정의 + 원본 표기 묶음, 해양 시스템 용어 |
| `about.html` | 데이터·검증 안내: 검증 단계 A~E 현황, 한계, 발표·논문 표현 가이드 |

필터 상태는 주소에 저장됩니다. 예) `index.html?asset=port_terminal&attack=ransomware` — 평가 과업 링크로 그대로 쓸 수 있습니다.

## 데이터 갱신

```bash
pip install pandas openpyxl
python tools/build_data.py data/source/maritime_incidents_all_897.xlsx
```

`data/incidents.json`이 다시 만들어집니다. 엑셀의 사람 검수 열(사건진위확인 등)을 채우면 화면의 검증 배지도 자동으로 바뀝니다.
번역 결과는 각 기록의 `i18n` 칸에 `{"ko": {"title": "...", "desc": "..."}}` 형태로 넣으면 화면에 "기계번역(검수 전)" 표시와 함께 나옵니다.

## 다국어

`js/i18n.js`(화면 문구)와 `js/dict.js`(분류값·통제·용어)에 한국어·영어·일본어·중국어가 들어 있습니다. 언어를 추가하려면 `LANGS`에 코드를 넣고 각 항목에 값을 추가하면 되며, 빠진 값은 영어로 대체됩니다. 국가명은 브라우저 내장 사전(Intl)으로 자동 번역됩니다.

## 제보 게시판 운영 시

`js/config.js`의 `reportApi`(저장 서버), `aiVerifyEndpoint`(AI 사실확인 중계 서버)를 채우면 됩니다. 비어 있으면 시연 모드(브라우저에만 저장)로 동작합니다.
LLM API 키는 절대 브라우저 코드에 넣지 말고, 서버에서 보관·요청 제한을 걸어 주세요.

## 보안 처리

- 외부 데이터는 모두 `esc()`로 이스케이프해 출력 (XSS 방지), 링크는 http/https만 허용
- 모든 페이지에 Content-Security-Policy 적용 (외부 스크립트·인라인 스크립트 차단)
- CSV 내보내기 시 엑셀 수식 주입 방지
- 제보: 개인정보(이메일·전화번호·주민번호 패턴) 자동 가림, 봇 차단용 숨김 칸, 연속 제출 제한
